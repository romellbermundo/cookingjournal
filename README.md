# Cooking Journal 🍳

A lightweight, mobile-first recipe journal for friends. No accounts, no API keys, no backend.

## Features
- Browse five starter recipe references from Matt Moore's *5 Awesome Recipes for the Man's-Man*.
- Add, edit, delete and search your own recipes.
- Recipes stay in your browser's local storage, private to that browser profile.
- Export and import JSON backups.
- Mobile-friendly, installable web app manifest.

## Live app
Once GitHub Pages is enabled: https://romellbermundo.github.io/cookingjournal/

## Deployment
Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub Pages may take a few minutes to publish.

## Privacy and limitations
Recipes you enter are stored in browser localStorage. There are no accounts, cloud sync, or shared recipe submissions. Clearing site data or using a different device/browser loses access unless you export and import a backup. Browser storage is not a secure vault; avoid storing sensitive information.

## Credits
The starter recipe titles and short descriptions link to the original article by **Matt Moore**, published on [The Art of Manliness](https://www.artofmanliness.com/culture/food-drink/5-awesome-recipes-for-the-mans-man/). Original full recipes are not reproduced.
